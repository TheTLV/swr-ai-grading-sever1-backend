(*) 3.1. Capstone Project name: 
English: Develop an AI-assisted system to support the grading of the Software Requirements (SWR30x) practical exam.
Vietnamese: Xây dựng hệ thống hỗ trợ chấm thi thực hành môn Software Requirements(SWR30x) có hỗ trợ từ AI.
a. Context:
Software Requirements (SWR30X) in FPTU  is one of the most important subjects in Software Engineering education because it establishes the foundation for the entire software development lifecycle. Students are expected to transform customer requirements into software artifacts such as stakeholder analysis, user stories, use cases, use case specifications, business rules, acceptance criteria, product backlogs, sprint plans, UML diagrams, and other project documents. However, evaluating these artifacts is highly time-consuming since each submission requires manual inspection of both textual content and diagrams.
Moreover, practical examinations (PEs) in Software Requirements typically require students to submit Microsoft Word documents containing textual descriptions, tables, diagrams, and embedded images. Instructors often spend significant effort opening hundreds of documents, locating required sections, interpreting embedded screenshots or diagrams, comparing student work with grading rubrics, and assigning scores consistently. Existing Learning Management Systems provide only basic assignment submission and file management features but lack intelligent assessment capabilities for software engineering artifacts.
Recent advances in Artificial Intelligence, Large Language Models (LLMs), Optical Character Recognition (OCR), and document understanding technologies provide new opportunities to automate both software engineering activities and educational assessment. AI can generate software engineering artifacts from customer requirements, detect inconsistencies among project documents. Additionally, AI can evaluate student submissions against predefined rubrics, extract textual content from images, separate images for rapid manual inspection, recommend scores, highlight missing sections, and provide learning analytics.
This project assists lecturers in preparing practical examinations, automatically grading student submissions, performing AI-assisted rubric evaluation, visualizing assessment results, and identifying students requiring further academic support.
