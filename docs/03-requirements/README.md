# 📋 03-requirements/ — Yêu cầu & Phạm vi

> **Mục đích:** Mô tả đầy đủ yêu cầu chức năng, phi chức năng, use case, phạm vi IN/OUT/DEFERRED, acceptance criteria.
> Đọc khi muốn biết **phải làm gì** và **không làm gì**.

## 📄 File trong thư mục này

| File | Mô tả |
|---|---|
| `requirements.md` | Yêu cầu chức năng (Functional), phi chức năng (Non-functional), Use cases theo actor, phạm vi, câu hỏi nghiệp vụ cần xác nhận |

## 🔍 Mục lục của `requirements.md`

1. Yêu cầu chức năng (Functional) — chia theo actor: Admin, Lecturer, Student, Examination Monitoring, Analytics, OCR, AI Explainability, Export
2. Yêu cứu phi chức năng — Performance, Scalability, Security, Operational
3. Use cases nghiệp vụ — Flow 1 (UC-01 → UC-22), Flow 2, Flow 3
4. Phạm vi (Scope) — IN-SCOPE / OUT-OF-SCOPE / DEFERRED
5. Actors của hệ thống — Admin, Khảo thí, Lecturer, Student
6. Câu hỏi nghiệp vụ còn mơ hồ — Q-01 → Q-10
7. Acceptance criteria cho Flow 1
8. Out of Flow 1 nhưng vẫn thuộc Server 1

## 🚦 Cách đọc

- Đánh dấu **[F1]** = thuộc Flow 1 (phạm vi bạn làm)
- Không đánh dấu = thuộc flow sau hoặc Server 2
